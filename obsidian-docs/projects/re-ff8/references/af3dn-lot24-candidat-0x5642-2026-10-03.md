# Candidat v15 `0x5642` — stage0 hook prouvé offline (Lot 24, 2026-10-03)

Fork append-only du v14 `0x5641` (sources Lot 22 intouchées). Build-id
**prouvé libre** (grep exhaustif ; builds connus `0x5638`→`0x5641`).

## 1. Deltas codec v14 → v15

| Élément | v15 |
| --- | --- |
| ST09 | **40 o** (10×u32 : +`ctx_token`, +`device_token` — bruts opaques, 0 = non capturé) |
| kinds | 1..7 inchangés + **kind 8** stage0 request / **kind 9** stage0 result (type = site ; **0 = site inconnu**, stub entré hors site patché) |
| kind2/6 | **aux = retour natif brut** (plus « call seule » ; jamais interprété HRESULT) |
| footer ND08 | **68 o** (17×u32 : +triple stage0 `tex/dev/devvt/hr` du dernier kind9, `st_emitted`, `st_lost`) |
| flags | bit0 (1) HAS_EPOCH ; **bit1 (2) STAGE0_VALID** (armé ET kind9 vu) ; bit2 (4) INCOMPLETE ; **bit3 (8) ST_LOSS** |
| pertes | tout refus **en fenêtre armée** (frame >4096, cap 1024, ring plein) = `broken`+`drops`+`lost`+bit3 ; **hors fenêtre = silencieux v14** |
| ND08 max | **`0x28188`** ⊂ garde `0x100C80` inchangée |

Sémantique lecteur : kind8 → `requested` ; kind9 avec `aux==0` →
**applied-witness** (hr brut préservé), `aux≠0` → `requested_failed` ;
bit1=0 ⇒ stage0 `unavailable` ; `st_loss_frame` sticky.

## 2. Stage0 hook (option B — les 2 call-sites SetTexture)

- Sites `0x41EF5D` (bind) / `0x41EF72` (unbind), préimage **6 o**
  `FF 90 98 00 00 00` → `E8 rel32` + `90`.
- **Stub naked exporté** (`Passthrough_Stage0Stub`) : pushad → logger kind8 →
  popad → réplication exacte des 3 args (offsets `[esp+16]` après chaque
  push) → `call [eax+98h]` → pushad → logger kind9 (hr, cache writer) →
  popad → **`ret 12` UNIQUE** — le stub **remplace le callee stdcall** :
  `[S]=site+5`, args `[S+4..C]` ; la forme « call direct » du harnais est
  identique. EAX = HRESULT propagé, canaries/esp préservés.
- **Installateur exporté fail-closed** : memcmp préimage, VirtualProtect RWX,
  écriture `E8 rel32`+`90` (borné), FlushInstructionCache, restore protection,
  préimages + ret VAs (`site+5`) gardés ; armé **ssi les 2 sites ok**, sinon
  restauration partielle + `g_stage0Broken` (bit1=0, dump dégradé continue).
  `Passthrough_RestoreStage0Hooks` = restauration byte-exact.
- **DllMain NON câblé** : installation explicite seulement (harnais / future
  carte live). Gap accepté : chemin `device==0` (sortie précoce sans call)
  non couvert.

## 3. Preuves (harnais + gate)

- Harnais natif (`tools/af3dn_state/harness_lot24.c`) : **648 assertions,
  0 fail, exit 0** — stub **fonctionnellement prouvé** dans un hôte
  synthétique : fake vtable `[+0x98]` → hr `0x1234`, args écho, canaries
  EBX/ESI/EDI/EBP intactes, esp équilibré, kind8/kind9 logués, footer
  bit1+triple ; restore byte-exact (bit1=0 au draw suivant) ; fail-closed

- **235 tests** au sweep global (fixtures env), exit 0.

## 4. Leçons de débogage (conservées dans la campagne)

`C2488` (naked = définition seulement) ; l'AV du stub via site venait de
**mon** `ret 16` : le stub **remplace** le callee stdcall — `ret 12` est le
seul épilogue correct des deux formes d'entrée (recomptage Astra) ; sentinelle
harnais = **`E9 jmp`** (aucun accès pile), cible révélée par un appel
warm-up ; probe BSS far : `0x140572C4` = RVA **`0x40572C4`** (soustraction de
base) ; hash du DLL dépend du **répertoire de build** (PDB embarqué) — build
canonique dans `lot24/`. Writer jamais corrigé pour satisfaire une attente de
harnais (les attentes ont été corrigées côté harnais).
