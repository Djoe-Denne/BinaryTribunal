# Tag Taxonomy

Canonical tags for this vault. Use lowercase, hyphenated tags and keep each page to five domain/type/project tags or fewer.

## Domain Tags

- `reverse-engineering` — Reverse engineering findings, tools, and workflows.
- `ff8` — Final Fantasy VIII-specific knowledge.
- `battle-system` — Battle runtime, combat mechanics, and battle data.
- `gforce` — Guardian Force / summon behavior and cinematics.
- `runtime-memory` — Addresses, globals, structs, buffers, and memory layout.
- `testing` — Verification plans, test protocols, and hypothesis evidence.
- `rendering` — Native/external render pipelines, GPU passes, composition, renderer migration, and engine integration.

## Type Tags

- `project` — Project overview pages.
- `concept` — Distilled conceptual knowledge.
- `reference` — Address tables, field maps, catalogs, and source references.
- `skill` — Repeatable procedure or workflow knowledge. Use this for AI prompts, Python tools, runner usage, YAML tests, IDA MCP workflows, and evidence-processing procedures.

## RE FF8 Classification Rule

- `docs/` sources usually become documentation: concepts or references about FF8 behavior, memory, addresses, and reverse-engineered architecture.
- `ai-prompt/`, `ff8re/`, `tools/`, Python files, executable YAML tests, and agent workflows usually become skills: reusable ways to investigate, validate, annotate, or update the documentation.
