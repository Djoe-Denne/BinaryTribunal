## Root cause — deferred step 4 (rejected)

`0x47D80C` / `0x47D811` are the **case 4** director tail (already ready).
Native U22.8 is **case 3**: write `mode_3_subsubsubstep = 4`, then pump
`Battle_RunFileLoadingCallbacks` + BdLink on the same frame.

The previous candidate wrote `MODE3_SUBSUB_STEP = 1` and left step ≠ 4
across `original()`. That skipped native's `subsub == 0` block, which is
the only path that sets `BATTLE_TRANSITION_COUNTDOWN = 0xFF`. With
countdown still 0, `original()` never entered the subsubsub switch, so
both observe hooks stayed at 0 (`g07_pump_status=no-observe`).

Do not retry defer-step-4. Do not treat a later case-4 tick pump as the
init-frame witness.
