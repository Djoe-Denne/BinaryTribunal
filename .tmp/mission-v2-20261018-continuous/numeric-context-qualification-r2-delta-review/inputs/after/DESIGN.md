## One closed observer and complete comparison

`observe` is the sole generic observer (a small bounded event writer, not a
planning trace framework). It accepts primitives, binary64 numbers, bigint,
ordinary/null-prototype records, arrays, native Maps and Sets. It encodes ordered
own DATA descriptors including nonenumerables, absence vs undefined/null, array
holes/length, ordered Map keys/values, ordered Set members, and stable per-stream
reference IDs. Representable cycles are reference events. Distinct aliases
remain distinct. Custom prototypes, symbols, functions, accessors, depth >128,
or ≥65536 first-seen objects are fatal. Error objects must take the explicit
refusal path; they are not silently coerced into generic records.

Numbers use `Buffer.writeDoubleBE` as eight raw binary64 bytes, including -0 and
nonfinite payloads. Event JSON is only an unambiguous **string-event envelope**;
it never serializes scientific numbers as JSON numbers. The whole streams are
compared directly. Hashes identify inputs/source files, not output equality.
In-test sensitivity assertions discriminate signed zero, own undefined, Map
order, aliasing and array holes. These too remain unexecuted proposals.

Each preparation guard and each action's complete input state is observed
before/after and must be identical, including the actual identities of all
first-seen object references. The optional reference sink supplements the same
single generic observer; it is not another serializer. A failed guarded call
still produces its finally-after proof. Guard failures are qualification failures,
never appairable scientific refusals. Stage before/after events, returned/refused
status, reference count/stability and raw stage errors are retained with the case.
Successful observations contain both the state and complete value, so output/
input aliases and all partitions, metrics, ordered diagnostics, projection
graphs, retained summands, caches, Maps, group documents, sidecars and digest
strings are compared without projections that discard fields.
