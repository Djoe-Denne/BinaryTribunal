## Faits structurels
- **Slot 46 (+0xB8)** : commit render-state + palette-resolve. (Mapping exact
  type de liste→slot 46 non établi dans ABI §6 ; seul le ctor 0x42597E est prouvé.)
- Même gate `*(a1+0x30)` et même matdesc `*(a1+0x38)` que le slot 45.
- Le bind passe par `sub_407EB4(idx, matdesc)` :
  - arg1 = idx de palette = `*(*(node+0x2C)+0x80)` (texinfo+0x80), guard -1 @0x43DF80,
  - arg2 = matdesc (a2 de sub_407EB4 — le « wrapper » de la chaîne palette-sprite
    fermée CLOSURE_walkdirect-texture-chain §2).
- `sub_407EB4` est le seul point de la chaîne qui ULTIMEMENT appel `sub_41ED69`
  (upload `sub_42022C` / SetTexture `sub_41EF3C` `call [deviceVT+0x98]` @0x41EF5D) —
  c'est le **bind effectif** de la texture D3D pour le groupe de draws qui suivent
  (walk slots 48/49/50 héritent de cet état device).
- AUCUN writer de `*(matdesc+0x14)` dans ce slot : le matdesc reste un état
  (blend/cull/zwrite), pas un cache texture (cf. CLOSURE_walkdirect-bind.md §2).
