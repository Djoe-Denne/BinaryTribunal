# G-Force Discovery Hub

This folder contains all G-Force investigation artifacts.

## Contents

- `domain_gf_*_invocation.md`: per-GF technical reconstruction reports.
- `domain_gf_batch_index.md`: consolidated index and confidence overview.
- `domain_gf_batch_inventory.json`: machine-readable extraction output.
- `domain_gf_batch_rollback.json`: rename rollback mapping (when annotation mode is used).
- `test/`: validation test plans for runtime spot-checking.
- `tools/`: tool wrappers/docs related to GF batch automation.
