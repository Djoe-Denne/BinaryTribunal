# Analyse de `domain::EnemyAI_VM_ExecuteScript` (0x487DF0 – 0x48A0B5)

## Avertissement méthodologique

Conformément à la consigne : les noms IDA (`USE_ABILITY`, `BOOL_TARGET_CHOOSEN`, `p_ai_current_subcode`…) sont traités comme des indices, jamais comme des preuves. Tout est re-dérivé depuis les instructions. Une anomalie majeure a été détectée entre annotations IDA et code réel (voir §1 et §10).

---

## 1. Structure générale et boucle principale — FACT

```
PROLOGUE (0x487DF0)
  ├── init locals (difficulty, first_ability, masques…)
  ├── test berserk (section==1 && status_1 & 0x20)
  │     ├── pas de vivants → esi=FALLBACK, param1=0, target=0, jmp 0x489804
  │     └── tirage vivant  → esi=FALLBACK, param1=0, target=1<<r, jmp 0x489804
  └── esi = [p_ai_current_subcode]        ; chargé UNE FOIS
BOUCLE (top ≈ 0x487EBA, cible des NOP 0x0A/0x10/0x14/0x21)
  op = *esi++; if (op==0) → épilogue (retour AL=0)
  if ((op-1) > 0x3C) → défaut
  dispatch jpt_487EDC[op-1]
  … handlers …
DÉFAUT (0x487EDC) = continuation de boucle → top
ÉPILOGUE (0x48A0AD): pop×4; add esp,64h; retn
```

Points structurels démontrés :

1. **esi est le pointeur d'instruction persistant** (FACT) — la preuve par contradiction : les opcodes 0x34/0x3B/0x1F écrasent `[esp+74h+p_ai_current_subcode]` avec un **index de slot (3..7 ou 0xFF)** puis sautent à `def_487EDC` sans le restaurer. Si la boucle rechargeait esi depuis ce local à chaque itération, l'itération suivante ferait `mov al,[esi]` avec esi=3..7 → faute. Donc `mov esi,[esp+74h+p_ai_current_subcode]` n'est exécuté qu'une fois à l'entrée.
2. **Le local `p_ai_current_subcode` est du scratch réutilisé** par les opcodes de spawn (FACT) — Hex-Rays produira un pseudo-code trompeur (§10).
3. **Le défaut du switch est la continuation de boucle** (FACT) : tous les handlers y convergent.
4. **Seules deux sorties** (FACT) : opcode 0x00 (retour AL=0) et `BOOL_TARGET_CHOOSEN≠0` post-commit (retour AL=flag). La « reprise » est externe : aucune position n'est sauvegardée, le script redémarre au prochain appel du moteur de bataille.

**Anomalie critique des annotations** (FACT de divergence) : le défaut IDA porte « cases 10,16,20,33 » = opcodes **0x0B, 0x11, 0x15, 0x22** → ces quatre opcodes **sautent directement au défaut = NOP purs**. Le commentaire d'en-tête « NOP pour 0x0A/0x10/0x14/0x21 » est donc **erroné** (0x0A/0x10/0x14/0x21 ont des jumptable-entries distinctes vers le top de boucle, cf. §2). Les handlers étiquetés 0x0B/0x11/0x15/0x22 dans le listing appartiennent en réalité à d'autres numéros — la numérotation annotée est décalée/inversée sur ce segment. Par élimination arithmétique (61 opcodes, 56 handlers distincts + 4 NOP-défaut + 1), le handler `1<<slot` non nommé est l'opcode **0x2B** (seul numéro non affecté).

## 2. Lecture du flux, avancement, dispatch — FACT

- **Lecture** : `mov al,[esi]; inc esi` — octet par octet, big-endian pour les mots (`movzx dx,[esi+1]; shl edx,8; add edx,eax` — vu en 0x23 et 0x3C).
- **Avancement** : chaque handler `inc esi` (ou `add esi,2/4`) après consommation ; le **JUMP (0x23) est relatif au point *après* l'opérande** (`add esi, jump` après les deux `add esi,2`), sign-étendu via `test ah,80h / or eax,0FFFF0000h` → offsets int16 négatifs OK.

## 10. Pièges Hex-Rays identifiés

1. **`p_ai_current_subcode` réécrit par 0x34/0x3B/0x1F** avec un slot — le décompilateur va montrer des usages incohérents du « pointeur de script » ; il faut le renommer en union scratch.
2. **Boucle** : Hex-Rays voudra hoister `mov esi,[local]` dans le while et casser les NOPs/le dispatch ; le top réel est `mov al,[esi]`.
3. **Berserk** : saut dans le *milieu* du handler 0x0C (post-opérande) — invisible en pseudo-C propre.
4. **`and eax,edi`** avec edi réutilisé comme 0xFF **et** comme pointeur d'abilité dans 0x0C/0x0B — le décompilateur peut mal typer edi.
5. **Multiplication par constantes** (5/10/13/15/20/71) en lea/shl/imul-magique — risque d'arrondi faux si simplifié (`sar` sans correction de signe vs avec).
6. **Modulo signé corrigé** (`and 80000003h…`) des cibles 0xCA/0xCF — un `%` naïf est infidèle.
7. **Les 4 NOPs réels (0x0B/0x11/0x15/0x22 par la table)** vs les NOPs annotés — toute re-numérotation sans vérifier `jpt_48A0B8` propage l'erreur.

## 12. Pseudo-C fidèle

```c
unsigned __int8 EnemyAI_VM_ExecuteScript(
    unsigned int  p_ai_subsection_init_code,   /* ebp — non lu dans ce corps */
    unsigned int  p_monster_slot_id,           /* slot 3..7 */
    unsigned __int8 *p_ai_current_subcode,     /* bytecode */
    int           p_text_subsection,
    int           p_text_offset_section)
{
    /* frame locale 0x64 ; noms = rôles observés */
    unsigned __int8 *ip;            /* esi — pointeur d'instruction persistant */
    unsigned int    slot = p_monster_slot_id;       /* ebx */
    unsigned int    base = (slot*13) << 4;          /* slot*0xD0 — recalculé localement partout */
    unsigned int    rank;          /* BMI71[slot*71] : 0/1/2 */
    ff8_battle_monster_info *minfo; /* edi = *slot.monster_info_section (380o) */
    unsigned __int8  cmd = 0;       /* command_type */
    unsigned __int16 section = 0;   /* section_position */
    unsigned __int8  anim = 0;      /* ai_scratch_var */
    unsigned __int8  param2 = 0;    /* enter_alt_target_param_2 */
    unsigned int     target_mask = 0;  /* p_monster_slot_id local */
    unsigned __int8  cond_result, lhs, rhs;  /* divers scratchs de l'IF */
    unsigned int     spawn_slot;    /* réutilise le slot du paramètre bytecode ! */

    rank  = BMI71_LOW_MED_HIGH_LEVEL_BIS[slot*71];
    minfo = *(ff8_battle_monster_info **)BATTLE_SLOT_DATA[slot].monster_info_section;

    /* ---- Berserk : remplace tout le script ---- */
    if (AI_CURRENT_SECTION_INDEX == 1
        && (BATTLE_SLOT_DATA[slot].status_1 & 0x20 /* Berserk */)) {
        if (EnemyAI_CountAlivePartyMembers() == 0xFF) {
            target_mask = 0;
        } else {
            do { r = Battle_GetRandomInt() & 0xFF; r %= 3; }   /* signé */
            while (BATTLE_SLOT_DATA[r].status_1 & 1);          /* mort → retire */
            target_mask = 1u << r;
        }
        ip = AI_VM_FALLBACK_BYTECODE;
        goto use_ability_body;   /* entre APRÈS la lecture d'opérande : idx=0 */
    }

    ip = p_ai_current_subcode;

    /* ================= BOUCLE ================= */
loop_top:                       /* cible des NOP 0x0A/0x10/0x14/0x21 */
    op = *ip++;

    if (op == 0x00)             /* STOP */
        return 0;               /* AL = 0 */

    if ((unsigned int)(op - 1) > 0x3C)
        goto loop_continue;     /* opcode invalide = NOP, pas une erreur */

    switch (op) {

    /* --- préparation (aucun effet externe) --- */
    case 0x03: cmd = 2;  section = *ip++;  goto loop_continue;   /* MAGIC */
    case 0x07: cmd = 8;  section = *ip++;  goto loop_continue;   /* MONSTER_ATTACK */
    case 0x05: anim = *ip++;               goto loop_continue;
    case 0x2B: target_mask = 1u << (*ip++); goto loop_continue;  /* bits 8-12 si >=8 ! */
    case 0x26: { u8 p1=*ip++, tgt=*ip++, cmp_=*ip++, st=*ip++;
                 target_mask = BattleTarget_SelectByStatusOrStat(p1,tgt,cmp_,st);
                 goto loop_continue; }

    /* --- variables --- */
    case 0x0E: { u8 i=*ip++, v=*ip++;
                 if (v==0xCB) v = BATTLE_SLOT_DATA[slot].last_attacker_slot_id;
                 BATTLE_LOCAL_VAR[base + i*4] = v; goto loop_continue; }
    case 0x12: { /* idem, += */ ... }
    case 0x0F: BATTLE_BATTLE_VAR[*ip*4] = *ip(ip+1); ...
    case 0x13: /* += */ ...
    case 0x11: SG_ITEM_ID_AND_QUANTITY.id[0x60 + i*4] = v; ...
    case 0x15: /* += */ ...

    /* --- contrôle de flux --- */
    case 0x23: { s16 off = be16(ip); ip += 2; ip += off; goto loop_continue; }
    case 0x02: {
        u8 subj=*ip++, param=*ip++, cmp_=*ip++;
        u16 value = be16(ip); ip += 2;
        u16 jump = be16(ip); ip += 2;
        if (subj > 0xE3) goto loop_continue;
        if (!IF_dispatch[subj](slot, param, cmp_, value, &locals)) /* §4 */
            { } else
            ip += jump;              /* VRAI → sauter (else) */
        goto loop_continue; }

    /* --- commit d'action --- */
    case 0x0C: {
        u8 idx = *ip++;
use_ability_body:                   /* entrée berserk : idx implicite = 0 */
        row = minfo->abilities[rank*16 + idx];   /* base+0x34, stride 4 :
                                                    {typeID, animscript, id:16} */
        cmd = row.typeID; section = row.id; anim = row.animscript;
        /* fall-through EXECUTE */ }
    case 0x06:
        if (section == 0) goto loop_continue;    /* rien de préparé */
        goto commit;
    case 0x0B: { u8 a=*ip++, b=*ip++, c=*ip++;
        r = (Battle_GetRandomInt() & 0xFF) % 3;
        idx = (r==0)?a:(r==1)?b:c;
        if (idx == 0xFD) goto loop_continue;
        row = minfo->abilities[rank*16 + idx];
        cmd=row.typeID; section=row.id; anim=row.animscript;
        goto commit_check; }
    case 0x1E: cmd=0xFC; section=1; param2=*ip++; goto commit;
    case 0x2A: { u8 m = BATTLE_SLOT_DATA[slot].magic_to_blow_away;
        cmd=2; section=m; anim=0x0B;
        target_mask = EnemyAI_GetTargetMaskFromMask(m);
        goto commit_check; }
    case 0x1B: { /* GF summon — commit inline, TOUJOURS continue */
        u8 s=*ip++, p=*ip++; u8 t = s+3;
        BattleEvent_ActivateTargetRelay(0x70,0x80,0);
        AI_PREPARE_SUMMON_FLAG = 1; cmd=0; section=3; anim=0; param2=p;
        target_mask = 1u << t;
        BattleAction_GetText(slot,0,3,locals.p3,p,target_mask,0);
        BattleAction_ResolveTargetAndHitCount(target_mask);
        BattleState_SetPhaseFlag(5);
        BattleEvent_EnqueueActionPresentation(ATTACK_HIT_COUNT-1);
        ACTION_EVENT_GROUP_INDEX[ATTACK_HIT_COUNT*5] = 0;
        BattleEvent_ActivateTargetRelay(0x71,0x80,EnemyAI_MonsterEnterAnimation);
        *(u8*)eax_ret = t;
        BattleState_SetPhaseFlag(6);
        goto loop_continue; }

    /* --- spawn / présence --- */
    case 0x34: case 0x3B: case 0x1F: {
        /* 0x34: id(1) ; 0x3B: id(1),slot(1) ; 0x1F: id(1) */
        ... /* si slot param == 0 : scan 3..7 flag_data bit0 == 0 */
        spawn_slot = found ? found : 0xFF;   /* ÉCRASE le local bytecode */
        BattleSlot_ManageDeathState(spawn_slot);
        BattleSlot_AddMonsterToRAM(spawn_slot, monster_id);
        ATTACKER_SLOT_ID_0[3]=spawn_slot; TARGET_SLOT_ID=monster_id;
        BattleEvent_ActivateTargetRelay(0x71,0x80,SceneOut_InitEnemySlot);
        BattleEvent_SetTargetableCallback(BattleAction_UnlockActionLatch);
        if (op==0x1F) { /* + relay 0x71 MonsterEnterAnimation, phase 6 */ }
        goto loop_continue; }

    /* --- texte --- */
    case 0x01: case 0x18: case 0x1A: case 0x22: case 0x1C: case 0x20:
    case 0x29: case 0x2E: case 0x25:
        ... /* §9 : résolution id via p_text_offset_section[id]*2
               (0xFFFF → RELATED_TO_AI_TEXT_SECTION_DEFAULT), affichage,
               DisplayMessageAndWait, buffers 1D28C4C/1D28C44/1D28E11-13 */
        goto loop_continue;

    /* --- effets de slot directs --- */
    case 0x24: BATTLE_SLOT_DATA[slot].cur_atb = .max_atb; ...
    case 0x16: .cur_hp = .max_hp; ...
    case 0x3C: .cur_hp += (s16)be16(ip); ip+=2; ...
    case 0x27: bit = (*ip<0x10)? status_1 : status_2 (bit-0x10);
                on = ip[1]; ip+=2; set/clear; ...
    case 0x28: BMI_MONSTER_STAT_PERCENT[slot*71 + stat] = pct;
               BattleSlot_ApplyMonsterStatScaling(slot); ...
    case 0x2D: BATTLE_SLOT_DATA[slot].elem_def[2*idx + 32] = be16; ...
    case 0x08: /* die */ case 0x1D: /* leave */ case 0x2C/0x2F/0x30/0x3A:
    case 0x31: case 0x32: case 0x33: case 0x35: case 0x36: case 0x37:
    case 0x38: case 0x39: case 0x3D: case 0x04: case 0x09:
    case 0x0D: case 0x19: /* réservés : consument leur opérande */
        ... /* §9 */ goto loop_continue;

    case 0x0A: case 0x10: case 0x14: case 0x21:
        goto loop_top;               /* NOP : ne repasse PAS par l'init esi */

    default:                          /* == cases NOP-défaut (cf. §1-A) */
    loop_continue:
        goto loop_top;
    }

    /* ============ COMMIT (LABEL_375 @ 0x48983D) ============ */
commit_check:
    if (section == 0) goto loop_continue;
commit:
    BATTLE_SLOT_DATA[slot].target_info_mask = target_mask;
    if (cmd == 2)        target_mask |= ComputeMaskFromDefaultTarget(K_MAGIC.defaultTarget[section*15]);
    else if (cmd == 4)   target_mask |= ComputeMaskFromDefaultTarget(K_ITEM.targetInfo[section*20]);
    else if (K_ENEMY_ATTACK.attackFlags[section*20] & 0x80) target_mask |= 0x4000;

    BattleAction_GetText(slot, cmd, section, p3, param2, target_mask, anim);
    BattleAction_ResolveTargetAndHitCount(target_mask);

    if (BOOL_TARGET_CHOOSEN != 0)
        return BOOL_TARGET_CHOOSEN;          /* AL = flag — YIELD */

    BattleState_SetPhaseFlag(5);
    BattleEvent_EnqueueActionPresentation(ATTACK_HIT_COUNT - 1);
    ACTION_EVENT_GROUP_INDEX[ATTACK_HIT_COUNT*5] = 0;

    if (BACK_PREEMTIVE_INFO_3 != 0) {        /* action enchaînée preemptive */
        m = byte_1D28DCD;
        mask = ComputeMaskFromDefaultTarget(K_MAGIC.defaultTarget[m*15])
             | EnemyAI_ResetExecState(byte_1D28DCE);
        BattleAction_GetText(slot, 0xF7, m, 0, 0, mask, 0);
        BattleAction_ResolveTargetAndHitCount(mask);
        BattleState_SetPhaseFlag(5);
        BattleEvent_EnqueueActionPresentation(ATTACK_HIT_COUNT - 1);
        ACTION_EVENT_GROUP_INDEX[ATTACK_HIT_COUNT*5] = 0;
        BattleState_SetPhaseFlag(6);
        BACK_PREEMTIVE_INFO_3 = 0;
        byte_1D28E0D = 0;
    }
    BattleState_SetPhaseFlag(6);
    EnemyAI_SyncAIVarsToSlot(slot);
    goto loop_continue;                       /* la VM CONTINUE */
}
```

**Architecture en résumé** : interprète à octets, registres virtuels persistants uniquement via les globals de bataille (locals du script = 8 slots 220-227), dispatch à deux niveaux (opcode → 17 familles IF → 6 comparateurs), sémantique de préparation/commit découplée (SET \* accumule, EXECUTE/USE \* déclenche), sortie exclusivement par STOP ou yield-sur-cible-verrouillée, RNG déterministe à lanes, et une injection berserk qui court-circuite le script en entrant à mi-chemin dans le handler d'abilité.
