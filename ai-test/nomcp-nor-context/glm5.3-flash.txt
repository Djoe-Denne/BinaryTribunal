# Analyse de `domain::EnemyAI_VM_ExecuteScript` @ 0x487DF0

## 1. Structure générale (FACT)

La fonction est un **interpréteur de bytecode à un accumulateur d'état local, boucle unique, dispatch par jump table**. Ce n'est PAS une machine à états au sens classique : c'est un interpréteur linéaire avec un seul point de sortie normal (opcode 0x00) et un point de sortie early-return (`BOOL_TARGET_CHOOSEN`).

```
Prologue (0x487DF0)
  ├─ slot_id (ebx) ← arg stack
  ├─ monster_difficulty ← BMI71_LOW_MED_HIGH_LEVEL_BIS[slot*71]   (table 71 octets/monstre)
  ├─ slot_base = BATTLE_SLOT_DATA + slot*0xD0                     (stride 208 = 0xD0)
  ├─ first_ability = *(slot->monster_info_section)                (déréférencement POINTEUR-DE-POINTEUR)
  ├─ init état local : target_mask=0, command_type=0, section_position=0,
  │   has_text_pending=0, ai_scratch_var=0, enter_alt_target_param_2=0
  └─ SI AI_CURRENT_SECTION_INDEX==1 ET slot->status_1 & 0x20 (Berserk):
       └─ cible = party aléatoire vivante (re-roll si morte), esi=AI_VM_FALLBACK_BYTECODE,
          param=0, JMP 0x489804  → exécute le bytecode de fallback (attaque forcée)
Boucle (top @ ~0x487ED0)  ← voir §2
Dispatch (jpt_487EDC, 61 entrées)
Handlers 0x01..0x3D
Commit tail LABEL_375 @ 0x48983D
Épilogue (pop edi/esi/ebp/ebx, add esp,64h, retn)
```

**FACT — stride des slots** : tous les accès slot utilisent `slot*13<<4` ou `slot*13*4<<4` → **208 = 0xD0 octets par slot**, 8 slots (0–2 = groupe, 3–7 = ennemis, confirmé par la boucle de comptage du test 17 qui scanne `status_1` jusqu'à `base+0x270` = slot 3).

**FACT — `first_ability` est un double déréférencement** : `mov ecx, BATTLE_SLOT_DATA.monster_info_section[eax]` puis `mov edi, [ecx]`. Le champ du slot est un pointeur vers un pointeur ; `edi` = base de la structure monstre (~380 octets). Les lignes d'abilité sont à `base+0x34`, stride 4, indexées par `16*difficulty + idx` (typeID @+0x34, animscript @+0x35, id word @+0x36). Tout handler qui lit `[edi+eax*4+34h]` utilise ce schéma.

## 2. Boucle principale et avance du flux (FACT)

```asm
top:
  mov esi, [esp+74h+p_ai_current_subcode]   ; rechargement DU POINTYPEUR depuis la pile
  mov al, [esi]
  inc esi                                    ; esi pointe DÉJÀ sur l'octet suivant
  test al, al
  mov [esp+74h+op_id], al
  jz  exit                                   ; 0x00 = STOP
  mov edi, 0FFh                              ; edi = masque 0xFF rétabli À CHAQUE itération
  mov edx, eax
  and edx, edi
  lea eax, [edx-1]
  cmp eax, 3Ch
  ja  top                                    ; op>0x3D → NOP silencieux (aucun operand consommé!)
  jmp ds:jpt_487EDC[eax*4]                   ; dispatch indexé op-1
```

Points essentiels :

1. **Le PC est `esi`**, rechargé depuis `[esp+74h+p_ai_current_subcode]` au top de chaque itération. Les handlers avancent `esi` octet par octet (`inc esi` / `add esi, n`) et la valeur finale d'`esi` est implicitement l'état du flux — mais **le stockage retour en pile n'est visible que sur certains chemins** (voir §9, suspension).
2. **Opcode 0x00 = terminaison** (`jz loc_48A0AD` → épilogue direct).
3. **Opcodes 0x0A, 0x10, 0x14, 0x21 = NOP sans opérande** : la jump table les renvoie vers `def_487EDC` (le top). Ils consomment **zéro octet**.
4. **Opcode invalide (>0x3D) = NOP silencieux** : `ja top` — aucun operand consommé, aucune erreur. C'est un détail important : un script corrompu ne crashe pas, il dérive.
5. **`edi = 0xFF` est un invariant de boucle** : c'est le masque `&0xFF` utilisé par tous les handlers (`and eax, edi`). Hex-Rays le perdra constamment.

## 3. Mécanisme de dispatch (FACT)

- **Jump table simple** `jpt_487EDC` @ 0x48A0B8, indexée `op-1`, 61 entrées (0x01..0x3D).
- **Dispatch secondaire pour 0x02** : table d'octets `byte_48A204` (index = subject 0..0xE3) → index de handler → `jpt_4887D6`. Puis pour certains subjects, **troisième niveau** : `byte_48A308` (param 0..0xCB) → `jpt_4887FB`, et `byte_48A4A4`/`byte_48A4E8`/`byte_48A52C`/`byte_48A588` (subject 0xC8..0xE3) → `jpt_488B83`/`jpt_488D0E`/`jpt_488F22`/`jpt_489535`.
- Les sujets **0xC8–0xE3** (200–227) forment une famille compacte : 200=self, 203=last_attacker_slot_id, 220–227=BATTLE_LOCAL_VAR[0..7], 201/202=groupes, 204–219=invalide→lhs=0.

## 4. Opérandes : largeur et interprétation (FACT)

Toutes les opérandes sont **inline, little-endian, immédiates** (pas de registres VM) :

| Forme | Lecture | Exemples |
|---|---|---|
| byte | `mov al,[esi]; inc esi` | 0x03, 0x04, 0x07, 0x09, 0x1C, 0x20, 0x25, 0x31, 0x37, 0x38, 0x35 |
| byte ×2 | deux lectures successives | 0x0E, 0x0F, 0x11, 0x12, 0x13, 0x15, 0x27, 0x28 |
| word LE | `movzx lo,[esi]; movzx hi,[esi+1]; shl hi,8; or/add` | 0x23 (saut), valeur de 0x02, delta de 0x3C, val de 0x2D |
| byte + word LE | — | 0x2D (idx, val16), 0x3C (delta16) |
| 7 bytes | subject(1) param(1) cmp(1) value(2LE) jump(2LE) | 0x02 |

**Interprétation des word** : les valeurs 16 bits sont assemblées non-signées puis, pour les sauts uniquement, **re-sign-étendues** (`test ah,80h; or eax,0FFFF0000h`). Les comparaisons 16 bits (`if_right_condition_final`) restent **non-signées** (`and 0FFFFh`, `cmp`/`ja`/`jb`).

## 6. Branchements (FACT)

**Un seul opcode de branchement conditionnel (0x02) et un inconditionnel (0x23)**, tous deux **relatifs à `esi`** (position juste après l'instruction), **signed 16-bit**.

Sémantique 0x02 : `if (compare(lhs, rhs, cmp_op) == FALSE) esi += (int16)jump;`
- Table des opérateurs : **0 = ==, 1 = <, 2 = >, 3 = !=, 4 = <=, 5 = >=** (validé par `EnemyAI_CompareValues` et les tails `jz/jb/ja/jnz/jbe/jnb → continue`).
- Subject > 0xE3 → condition traitée comme "continue" (pas de saut).
- Cas particulier élément (subject → last_attacker_attack_element) : `==` teste `mask & (1<<value)`, `!=` teste bit clair, **tout autre cmp_op → toujours "faux" → saut inconditionnel**.

## 10. Subtilités signed/unsigned / pointeurs (FACT)

1. `and eax, edi` avec **edi=0xFF rétabli à chaque itération** — Hex-Rays va souvent le matérrialiser comme variable `v_N` et perdre la trace.
2. `cdq/idiv` = division signée ; `and 80000003h` + correction = modulo signé inline.
3. Les word d'opérande sont **assemblés non-signé** puis **sign-étendus uniquement pour 0x23 et le saut de 0x02**.
4. `monster_info_section` est un **pointeur de pointeur** — Hex-Rays générera `*(DWORD**)` ou perdra un niveau.
5. `elem_def[edx*2]` : l'index est déjà multiplié par 104 (`slot*13*8`) → `edx*2` donne le byte offset `slot*208 + idx*2`. Hex-Rays va afficher `elem_def` comme tableau d'u16 avec un index bizarre.
6. Le scan "premier slot libre" utilise `jl` vers `BATTLE_SLOT7_FLAG_DATA` : le **dernier slot testé est celui dont l'adresse est strictement inférieure** au label. Si le label pointe sur le slot 7, le slot 7 n'est jamais testé (spawn 3..6). À vérifier par l'adresse réelle du label.
7. `movsx edx, ax` après `LookupAbilityByIndex` : le résultat est signé ; un retour négatif produirait un index négatif dans `dword_1D28C44[idx*16]` — non gardé.

## 11. Pièges Hex-Rays

- `edi = 0xFF` réutilisé comme masque → Hex-Rays va le renommer en variable locale et dupliquer.
- Le **fall-through 0x0C → 0x06** : Hex-Rays va dupliquer le bloc de commit ou créer un `goto`.
- Le **fall-through 0x0D → 0x19** (deux NOP avec consommation d'1 byte) : Hex-Rays va fusionner en un seul case.
- Le **jump `jmp loc_48813E`** de 0x3B vers l'intérieur du handler 0x1F : Hex-Rays va dupliquer tout le bloc ou créer un label bizarre.
- Les `push`/`add esp` déséquilibrés (`add esp, 1Ch` pour 7 args = 28 bytes ✓, mais `add esp, 14h` après DisplayText+DisplayMessageAndWait = 20 bytes pour 5+1 args → **DisplayText est stdcall** ou un arg passe en registre).
- Les tables de dispatch secondaires (`byte_48A204`, `byte_48A308`, etc.) seront inlinées en switch géant.

# 13. Architecture de l'interpréteur

C'est un **interpréteur à bytecode inline, à thread unique, avec commit d'action en queue et suspension implicite par early-return**. Le "PC" vit dans `esi` + une ombre en pile (`[esp+74h+p_ai_current_subcode]`). Le VM ne gère pas de pile d'exécution, pas d'appel, pas de boucle native — toute la logique de contrôle est dans le script via 0x02/0x23. Le modèle de données est un **état de bataille global partagé** (slots, vars, items) que le VM lit/écrit directement, sans couche d'abstraction. Le "commit" est le seul point de synchronisation avec le moteur de bataille (payload + phase flags + presentation queue) ; tout le reste est soit de la manipulation d'état pur, soit du relay d'événement asynchrone.

Le design "Berserk → fallback bytecode" en prologue est un **hijack du flux avant la première instruction** : le VM est réorienté vers un bytecode système (`AI_VM_FALLBACK_BYTECODE`) qui contient vraisemblablement une séquence d'attaque minimale, sans que le script du monstre ne s'exécute du tout.

# 15. Pseudo-C fidèle

```c
// Fidèle au comportement observable. Les noms suivent le dump IDA.
// Conventions : slot_id = ebx (0..7), 0-2 = groupe, 3-7 = ennemis.
// Stride slot = 0xD0 (208). edi = 0xFF rétabli à chaque itération = masque byte.

#define SLOT_BASE(slot)   (BATTLE_SLOT_DATA + (slot) * 0xD0)
#define LOCAL_VAR(slot,i) (*(int*)(BATTLE_LOCAL_VAR + (slot)*0xD0 + (i)*4))
#define BATTLE_VAR(i)     (*(int*)(BATTLE_BATTLE_VAR + (i)*4))
#define ITEM_QTY(i)       (*(int*)(SG_ITEM_ID_AND_QUANTITY + 0x60 + (i)*4))

uint8_t EnemyAI_VM_ExecuteScript(
    /* ebp */ uint32_t p_ai_subsection_init_code,   // non lu dans ce dump
    uint32_t p_monster_slot_id,                      // slot_id
    uint8_t *p_ai_current_subcode,                   // PC initial
    int p_text_subsection,
    int p_text_offset_section)                       // table de words (offsets)
{
    uint8_t  stack[0x64];                            // cadre de 0x64 bytes
    uint32_t slot_id       = p_monster_slot_id;
    uint32_t target_mask   = 0;                      // [esp+74h+p_monster_slot_id]
    uint8_t  command_type  = 0;
    uint16_t section_position = 0;
    uint8_t  ai_scratch_var = 0;
    uint8_t  has_text_pending = 0;
    uint8_t  enter_alt_target_param_2 = 0;
    uint8_t  monster_difficulty = BMI71_LOW_MED_HIGH_LEVEL_BIS[slot_id * 71];
    uint8_t *first_ability = *(uint8_t***)SLOT_BASE(slot_id)->monster_info_section; // double déréf.
    uint8_t *pc = p_ai_current_subcode;

    // --- Prologue Berserk (section 1 uniquement) ---
    if (AI_CURRENT_SECTION_INDEX == 1 && (SLOT_BASE(slot_id)->status_1 & 0x20)) {
        int cnt = EnemyAI_CountAlivePartyMembers();
        if (cnt == 0xFF) {
            target_mask = 0;
        } else {
            int s;
            do {
                s = Battle_GetRandomInt() & 0xFF;
                s = s % 3;                              // idiv signé, EAX positif
            } while (SLOT_BASE(s)->status_1 & 1);       // re-roll si mort
            target_mask = 1u << s;
        }
        pc = AI_VM_FALLBACK_BYTECODE;
        goto commit_tail;                               // 0x489804 → stocke pc, exécute
    }

    // --- Boucle principale ---
    for (;;) {
        uint8_t op = *pc++;
        if (op == 0x00) return 0;                       // STOP
        uint32_t mask = 0xFF;                           // edi

        switch (op) {
        case 0x24: { // RESET_ATB_SELF
            auto *s = SLOT_BASE(slot_id);
            s->atb_cur = s->atb_max;                    // +0x14 = +0x10
            break;
        }
        case 0x1C: { // SET_TEXT_FRAMES_30
            uint8_t n = *pc++;
            int idx = EnemyAI_LookupAbilityByIndex(n, EnemyAI_AbilityLookupCallback);
            *(uint16_t*)((char*)dword_1D28C44 + idx*16 + 8) = 30 * n;
            break;
        }
        case 0x20: { // SET_TEXT_FRAMES_15
            uint8_t n = *pc++;
            int idx = EnemyAI_LookupAbilityByIndex(n, EnemyAI_AbilityLookupCallback);
            *(uint16_t*)((char*)dword_1D28C44 + idx*16 + 8) = 15 * n;
            break;
        }
        case 0x34: { // SPAWN_MONSTER
            uint8_t id = *pc++;
            int slot = find_first_free_enemy_slot();    // 3..(6|7), flag bit0 == 0
            spawn_common(slot, id);
            // relay 0x71 + SceneOut_InitEnemySlot, unlock latch, PAS de phase 6
            break;
        }
        case 0x3B: { // SPAWN_TO_SLOT
            uint8_t id = *pc++;
            uint8_t slot_arg = *pc++;
            int slot = slot_arg ? slot_arg : find_first_free_enemy_slot();
            spawn_common(slot, id);
            goto enter_anim_tail;                       // partage le tail de 0x1F
        }
        case 0x1F: { // ENTER_MONSTER
            uint8_t id = *pc++;
            int slot = find_first_free_enemy_slot();
            spawn_common(slot, id);
        enter_anim_tail:
            // relay 0x71 + MonsterEnterAnimation (param = slot)
            BattleEvent_SetTargetableCallback(BattleAction_UnlockActionLatch);
            BattleState_SetPhaseFlag(6);
            break;
        }
        case 0x1B: { // GF_SUMMON_PRESENT
            uint8_t p1 = *pc++;  p1 += 3;
            uint8_t p2 = *pc++;
            BattleEvent_ActivateTargetRelay(0x70, 0x80, 0);
            uint32_t m = 1u << p1;
            AI_PREPARE_SUMMON_FLAG = 1;
            command_type = 0; section_position = 3; ai_scratch_var = 0;
            BattleAction_GetText(slot_id, 0, 3, p1, p2, m, 0);
            BattleAction_ResolveTargetAndHitCount(&m);
            BattleState_SetPhaseFlag(5);
            BattleEvent_EnqueueActionPresentation(ATTACK_HIT_COUNT - 1);
            ACTION_EVENT_GROUP_INDEX[20*ATTACK_HIT_COUNT] = 0;
            BattleEvent_ActivateTargetRelay(0x71, 0x80, EnemyAI_MonsterEnterAnimation); // [eax]=p1
            BattleState_SetPhaseFlag(6);
            break;
        }
        case 0x2E: case 0x29: { // READ_PLAYER_MAGIC_B / A
            uint8_t list[...]; 
            uint16_t m = SLOT_BASE(slot_id)->target_info_mask;
            Battle_GetElementFlagged(m, list);
            uint8_t magic = EnemyAI_SelectRandomMagicFromPlayer(list[0] & 0xFF, 0);
            SLOT_BASE(slot_id)->magic_to_blow_away = magic;
            if (magic != 0xFF) {
                if (op == 0x2E) {
                    uint8_t m2 = EnemyAI_SelectRandomMagicFromStock(magic, SLOT_BASE(slot_id)->magic_to_blow_away);
                    byte_1D28E13 = m2;
                    // texte misc 0x75 + GetMagicName + GetCharacterName
                } else {
                    byte_1D28E13 = 1;
                    // texte misc 0x76 + GetMagicName + FormatNumber(qté) + misc 0x13
                }
                byte_1D28E11 = 2; byte_1D28E12 = magic;
                BattleEvent_DisplayMessageAndWait(BattleText_Print(...));
            }
            break;
        }
        case 0x1A: { // SET_ATTACK_TEXT
            uint8_t id = *pc++;
            uint16_t off = ((uint16_t*)p_text_offset_section)[id];
            int resolved = (off == 0xFFFF) ? RELATED_TO_AI_TEXT_SECTION_DEFAULT
                                           : off + p_text_subsection;
            int idx = EnemyAI_LookupAbilityByIndex(resolved, EnemyAI_TextAfterAttackCallback);
            uint32_t *row = (uint32_t*)((char*)dword_1D28C44 + idx*16);
            row[1] = BattleScript_DisplayText(resolved, ...);
            break;
        }
        case 0x22: { // SET_ATTACK_TEXT_PARAM
            uint8_t id = *pc++; uint8_t param = *pc++;
            uint16_t off = ((uint16_t*)p_text_offset_section)[id];
            int resolved = (off == 0xFFFF) ? RELATED_TO_AI_TEXT_SECTION_DEFAULT
                                           : off + p_text_subsection;
            int idx = EnemyAI_LookupAbilityByIndex(resolved, EnemyAI_TextWithParamCallback);
            uint32_t *row = (uint32_t*)((char*)dword_1D28C44 + idx*16);
            row[1] = BattleScript_DisplayText(resolved, ...);
            row[2] = param;
            break;
        }
        case 0x18: { // SHOW_TEXT_WAIT2
            uint8_t id = *pc++;
            uint16_t off = ((uint16_t*)p_text_offset_section)[id];
            int resolved = (off == 0xFFFF) ? RELATED_TO_AI_TEXT_SECTION_DEFAULT
                                           : off + p_text_subsection;
            uint32_t spd = SG_BATTLE_MESSAGE_SPEED_SETTING;
            int h = BattleScript_DisplayText(resolved, 8*spd+8, 1, 0x80, 0);
            BattleEvent_DisplayMessageAndWait(h);
            break;
        }
        case 0x01: { // SHOW_TEXT_WAIT
            uint8_t id = *pc++;
            uint16_t off = ((uint16_t*)p_text_offset_section)[id];
            int resolved = (off == 0xFFFF) ? RELATED_TO_AI_TEXT_SECTION_DEFAULT
                                           : off + p_text_subsection;
            int h = BattleScript_DisplayText(resolved, 0x1E, 3, 0x80, 0);
            BattleEvent_DisplayMessageAndWait(h);
            break;
        }
        case 0x25: { // SCAN_STORE
            uint8_t id = *pc++;
            if (id == 0xFF) {
                BMI_SCAN_BUFFER[71*(slot_id-3)] = 0;
            } else {
                uint16_t off = ((uint16_t*)p_text_offset_section)[id];
                int src = (off == 0xFFFF) ? RELATED_TO_AI_TEXT_SECTION_DEFAULT
                                          : off + p_text_subsection;
                memcpy(BMI_SCAN_BUFFER + 71*(slot_id-3), (void*)src, 0x18);
            }
            break;
        }
        case 0x0E: { // SET_LOCAL_VAR
            uint8_t idx = *pc++; uint8_t val = *pc++;
            if (val == 0xCB) val = SLOT_BASE(slot_id)->last_attacker_slot_id;
            LOCAL_VAR(slot_id, idx) = val;
            break;
        }
        case 0x0F: { // SET_BATTLE_VAR
            uint8_t idx = *pc++; uint8_t val = *pc++;
            BATTLE_VAR(idx) = val;
            break;
        }
        case 0x11: { // SET_ITEM_SLOT
            uint8_t idx = *pc++; uint8_t val = *pc++;
            ITEM_QTY(idx) = val;
            break;
        }
        case 0x12: { // ADD_LOCAL_VAR
            uint8_t idx = *pc++; uint8_t val = *pc++;
            if (val == 0xCB) val = SLOT_BASE(slot_id)->last_attacker_slot_id;
            LOCAL_VAR(slot_id, idx) += val;
            break;
        }
        case 0x13: { // ADD_BATTLE_VAR
            uint8_t idx = *pc++; uint8_t val = *pc++;
            BATTLE_VAR(idx) += val;
            break;
        }
        case 0x15: { // ADD_ITEM_SLOT
            uint8_t idx = *pc++; uint8_t val = *pc++;
            ITEM_QTY(idx) += val;
            break;
        }
        case 0x2D: { // SET_RES_FIELD
            uint8_t idx = *pc++;
            uint16_t val = pc[0] | (pc[1] << 8); pc += 2;
            *(uint16_t*)(SLOT_BASE(slot_id) + 2*idx) = val;   // elem_def
            break;
        }
        case 0x02: { // IF
            uint8_t subject = *pc++;
            uint8_t param   = *pc++;
            uint8_t cmp_op  = *pc++;
            uint16_t value  = pc[0] | (pc[1] << 8); pc += 2;
            uint16_t jump   = pc[0] | (pc[1] << 8); pc += 2;
            if (subject > 0xE3) break;                        // ignore
            int lhs = resolve_subject_lhs(subject, param, slot_id, value);
            // lhs dépend de la table byte_48A204 → handler → byte_48A308/48A4A4/…
            int rhs = value;
            bool cond;
            switch (cmp_op) {
            case 0: cond = (lhs == rhs); break;
            case 1: cond = (lhs <  rhs); break;
            case 2: cond = (lhs >  rhs); break;
            case 3: cond = (lhs != rhs); break;
            case 4: cond = (lhs <= rhs); break;
            case 5: cond = (lhs >= rhs); break;
            }
            if (!cond) pc += (int16_t)jump;                   // sign-extend
            break;
        }
        case 0x23: { // JUMP
            uint16_t off = pc[0] | (pc[1] << 8); pc += 2;
            pc += (int16_t)off;
            break;
        }
        case 0x0C: { // USE_ABILITY
            uint8_t idx = *pc++;
            uint8_t *row = first_ability + 4*(16*monster_difficulty + idx) + 0x34;
            command_type     = row[0];
            section_position = *(uint16_t*)(row+2);
            ai_scratch_var   = row[1];
            /* fall-through */
        }
        case 0x06: { // EXECUTE
            if (section_position == 0) break;
        commit_tail: ;
            uint32_t m = target_mask;
            if (command_type == 2)
                m |= BattleTarget_ComputeMaskFromDefaultTarget(
                        K_MAGIC.defaultTarget[16*section_position + ...]);
            else if (command_type == 4)
                m |= BattleTarget_ComputeMaskFromDefaultTarget(
                        K_ITEM.targetInfo[16*section_position + ...]);
            else if (K_ENEMY_ATTACK.attackFlags[20*section_position + ...] & 0x80)
                m |= 0x4000;
            target_mask = m;
            BattleAction_GetText(slot_id, command_type, section_position,
                                 enter_alt_target_param_2, target_mask, m, ai_scratch_var);
            BattleAction_ResolveTargetAndHitCount(&m);
            if (BOOL_TARGET_CHOOSEN) return 0;                // suspension
            BattleState_SetPhaseFlag(5);
            BattleEvent_EnqueueActionPresentation(ATTACK_HIT_COUNT - 1);
            ACTION_EVENT_GROUP_INDEX[20*ATTACK_HIT_COUNT] = 0;
            if (BACK_PREEMTIVE_INFO_3 != 0) {
                // contre Odjin/Gilgamesh : cmd 0xF7, arg=byte_1D28DCD, param=byte_1D28DCE
                EnemyAI_ResetExecState(byte_1D28DCE, ...);
                BattleAction_GetText(slot_id, 0xF7, byte_1D28DCD, 0, 0, m2, 0);
                BattleAction_ResolveTargetAndHitCount(&m2);
                BattleState_SetPhaseFlag(5);
                BattleEvent_EnqueueActionPresentation(ATTACK_HIT_COUNT - 1);
                BattleState_SetPhaseFlag(6);
                BACK_PREEMTIVE_INFO_3 = 0; byte_1D28E0D = 0;
                BattleState_SetPhaseFlag(6);
                EnemyAI_SyncAIVarsToSlot(slot_id);
            }
            break;
        }
        case 0x0D: case 0x19: // NOP 1-byte
            pc += 1; break;
        case 0x0A: case 0x10: case 0x14: case 0x21: // NOP 0-byte
            break;
        case 0x16: { // FULL_HEAL_SELF
            auto *s = SLOT_BASE(slot_id);
            s->current_hp = s->max_hp;                     // +0x18 = +0x1C
            break;
        }
        case 0x17: { // SET_ESCAPE_FLAG
            uint8_t on = *pc++;
            if (on == 1) ENCOUTER_BATTLE_FLAG |= 1;
            else         ENCOUTER_BATTLE_FLAG &= ~1;
            break;
        }
        case 0x27: { // SET_AUTO_STATUS_SELF
            uint8_t st = *pc++; uint8_t on = *pc++;
            auto *s = SLOT_BASE(slot_id);
            if (st < 16) {
                if (on == 1) s->status_1 |=  (1u << st);
                else         s->status_1 &= ~(1u << st);
            } else {
                if (on == 1) s->status_2 |=  (1u << (st-16));
                else         s->status_2 &= ~(1u << (st-16));
            }
            break;
        }
        case 0x28: { // SET_MONSTER_STAT_PCT
            uint8_t stat = *pc++; uint8_t pct = *pc++;
            BMI_MONSTER_STAT_PERCENT[71*(slot_id-1) + stat] = pct;
            BattleSlot_ApplyMonsterStatScaling(slot_id);
            break;
        }
        case 0x09: { // SET_HIT_ANIM
            HIT_TYPE_TARGET_ANIMATION_TO_PLAY = *pc++;
            break;
        }
        case 0x05: { // SET_SCRATCH
            ai_scratch_var = *pc++;
            break;
        }
        case 0x1E: { // CHOCOBO_ACTION
            uint8_t code = *pc++;
            command_type = 0xFC; section_position = 1;
            enter_alt_target_param_2 = code;
            goto commit_tail;
        }
        case 0x2A: { // CAST_READ_MAGIC
            command_type = 2;
            section_position = SLOT_BASE(slot_id)->magic_to_blow_away;
            target_mask = EnemyAI_GetTargetMaskFromMask(section_position);
            ai_scratch_var = 0x0B;
            goto commit_tail;
        }
        case 0x26: { // TARGET_BY_STATUS_STAT
            uint8_t p1 = *pc++; uint8_t p2 = *pc++; uint8_t p3 = *pc++; pc++;
            target_mask = BattleTarget_SelectByStatusOrStat(p1, p2, p3, pc[-1]);
            break;
        }
        case 0x04: { // CHOOSE_TARGET
            uint8_t code = *pc++;
            switch (code) {
            case 0xC8: target_mask = 1u << slot_id; break;
            case 0xC9: { int s; do { s = rnd()%3; } while (dead(s)); target_mask = 1u<<s; break; }
            case 0xCA: { int s; do { s = rnd()%4+3; } while (dead(s)); target_mask = 1u<<s; break; }
            case 0xCB: target_mask = 1u << SLOT_BASE(slot_id)->last_attacker_slot_id; break;
            case 0xCC: target_mask = 0x8007; break;
            case 0xCD: target_mask = 0x80F8; break;
            case 0xCE: target_mask = 0x80FF; break;
            case 0xCF: { /* rnd parmi ennemis vivants != self */ break; }
            case 0xD0: target_mask = 0xA007; break;
            case 0xD1: target_mask = 1u << (ATTACKER_SLOT_ID_0 >> 24); break;
            default:
                if (code >= 0xDC && code <= 0xE3)  // 220-227
                    target_mask = 1u << LOCAL_VAR(slot_id, code-220);
                else if (code >= 0xC8 && code <= 0xE3) { /* scan com_file_id */ }
                break;
            }
            break;
        }
        case 0x1D: { // ENEMY_LEAVE
            uint8_t code = *pc++;
            uint8_t s = (code == 0xC8) ? slot_id : code + 3;
            BattleEvent_ActivateTargetRelay(0x69, 0x80, 0); // [eax]=s
            BattleState_ResetForEject(slot_id);
            break;
        }
        case 0x08: { // DIE_SELF
            BattleEvent_ActivateTargetRelay(0x6A, 0x80, 0); // [eax]=slot_id
            SLOT_BASE(slot_id)->status_1 |= 1;
            BattleState_ResetForEject(slot_id);
            break;
        }
        case 0x2C: { // REMOVE_SELF_HIDDEN
            BattleState_ResetForEject(slot_id);
            SLOT_BASE(slot_id)->flag_data |= 0x40;
            Battle_BuildTargetVisibilityMasks();
            SLOT_BASE(slot_id)->status_1 |= 1;
            SLOT_BASE(slot_id)->flag_data &= ~1u;
            break;
        }
        case 0x2F: case 0x3A: { // SHOW_SELF / SHOW_SLOT
            int s = (op == 0x2F) ? slot_id : *pc++;
            SLOT_BASE(s)->flag_data &= ~0x40;
            BattleEvent_SetTargetableCallback(Battle_BuildTargetVisibilityMasks);
            break;
        }
        case 0x30: { // HIDE_SELF
            SLOT_BASE(slot_id)->flag_data |= 0x40;
            BattleEvent_SetTargetableCallback(Battle_BuildTargetVisibilityMasks);
            break;
        }
        case 0x31: { // GIVE_GF
            uint8_t gf = *pc++;
            GF_SetOwnedFlag(gf);
            POST_BATTLE_GF_ID_QUEUE[POST_BATTLE_GF_ID_QUEUE_COUNT++] = gf;
            break;
        }
        case 0x32: AI_PREPARE_SUMMON_FLAG = 1; break;
        case 0x33: BattleEvent_ActivateTargetRelay(0x70, 0x80, 0); break;
        case 0x35: { // ENTER_ANIM_TARGET
            uint8_t code = *pc++;
            uint8_t s = (code == 0xD1) ? (ATTACKER_SLOT_ID_0 >> 24) : code;
            BattleEvent_ActivateTargetRelay(0x71, 0x80, EnemyAI_MonsterEnterAnimation);
            // [eax] = s
            break;
        }
        case 0x36: SG_ODIN_ANGEL_GILGA_FLAG = (SG_ODIN_ANGEL_GILGA_FLAG & 0xFD) | 8; break;
        case 0x37: { // GIVE_CARD
            uint8_t id = *pc++;
            BATTLE_CARD_DROP[NB_CARD_OBTAINED++] = id;
            break;
        }
        case 0x38: { // GIVE_ITEM
            uint8_t id = *pc++;
            int n = ATTACKER_SLOT_ID_0_byte2;
            ITEM_RELATED[n*2] = id;
            ITEM_RELATED_0[n*2] = 1;
            ATTACKER_SLOT_ID_0_byte2 = n + 1;
            break;
        }
        case 0x39: BATTLE_SCRIPTED_END_PENDING = 1; break;
        case 0x3C: { // MOD_HP_SELF
            int16_t delta = pc[0] | (pc[1] << 8); pc += 2;
            SLOT_BASE(slot_id)->current_hp += delta;
            break;
        }
        case 0x3D: Savegame_GiveProofOfOmega(0x7F); break;
        case 0x0B: { // USE_RANDOM_ABILITY_3
            uint8_t a = pc[0], b = pc[1], c = pc[2]; pc += 3;
            int k = (Battle_GetRandomInt() & 0xFF) % 3;
            uint8_t pick = (k==0)?a:(k==1)?b:c;
            if (pick == 0xFD) break;
            uint8_t *row = first_ability + 4*(16*monster_difficulty + pick) + 0x34;
            command_type = row[0];
            section_position = *(uint16_t*)(row+2);
            ai_scratch_var = row[1];
            goto commit_tail;
        }
        default: break;   // op > 0x3D : NOP, aucun operand
        }
    }
}
```

**Note finale** : le pseudo-C ci-dessus ne modernise pas — il préserve les fall-through (0x0C→0x06, 0x3B→tail 0x1F), le goto `commit_tail`, l'ordre exact des arguments de `GetText` tels que poussés, et le fait que `target_mask` est à la fois une variable locale réinitialisée à chaque itération implicite (via `mov [esp+74h+p_monster_slot_id], esi/edi`) et un paramètre de sortie des handlers 0x04/0x26. Hex-Rays générera quelque chose de nettement plus confus à cause des `edi=0xFF`, des jumps croisés entre handlers, et des tables de dispatch à trois niveaux.
